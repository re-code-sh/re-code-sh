### 🪐 About Me

I am a software engineer and systems explorer dedicated to engineering resilient, privacy-conscious tools and high-performance offline-first applications. My focus centers on deep system internals, fluid user interfaces, and intentional software architecture.

- 🐧 **Linux & Systems**: Deep exploration of system internals, desktop environments, shell scripting, and zero-bloat computing.
- ⚡ **Offline-First & Local Persistence**: Building applications that prioritize local storage, reactive state, and resilience.
- 📱 **Cross-Platform & UI Craft**: Engineering fluid, tactile interfaces across mobile and web with intentional gesture physics.
- 🛡️ **Privacy & Security**: Passionate about zero-telemetry architectures, open-source freedom, and hardened systems.
- 💡 **Engineering Philosophy**: *"Don't Vibe Coding — write real, robust, and maintainable code."*
