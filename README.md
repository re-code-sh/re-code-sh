### 🪐 About Me

I am a software engineer and systems explorer dedicated to engineering resilient, privacy-conscious tools and high-performance offline-first applications. My craft bridges system internals, Linux desktop customization, cross-platform mobile apps with Flutter, and fluid web experiences.

- ⚡ Architecting **[ReFlow PWA](https://github.com/re-code-sh/re-flow-pwa)** — an offline-first productivity platform featuring Dexie.js local persistence, liquid-glass aesthetic tokens, and bilingual RTL/LTR parity.
- 🗺️ Building **[Istgah (Bus)](https://github.com/re-code-sh/bus)** — high-speed interactive transit and urban station mapping with layered vector canvases.
- 📱 Engineering **[re-flow](https://github.com/re-code-sh/re-flow)** — the mobile Flutter productivity counterpart with tactile haptic physics and flow-state analytics.
- ⌨️ Maintaining **[HeliKey](https://github.com/re-code-sh/HeliKey)** — privacy-first, zero-telemetry customizable keyboard for Android written in Kotlin.
- 🛡️ Curating **[Claude-BugHunter](https://github.com/re-code-sh/Claude-BugHunter)** — comprehensive offensive security matrices, red-teaming playbooks, and automated audit skills.
- 🐧 Experimenting with Linux desktop shells (**[impactolia](https://github.com/re-code-sh/impactolia)** / **[impastolia](https://github.com/re-code-sh/impastolia)**) combining C++ and QML interfaces.
